# bob_sessions/

This directory must contain screenshots of IBM Bob 2.0 task session summaries.

## Required Files

After completing each major task in the IBM Bob 2.0 IDE:

1. Open the Tasks panel in Bob IDE
2. Select the completed task
3. Screenshot the task session consumption summary
4. Save as PNG with the naming convention below

## File Naming Convention

```
patchflow_task<NN>_<short-description>_summary.png
```

## Expected Files

| File | Task | When to capture |
|------|------|-----------------|
| `patchflow_task01_scaffolding_summary.png` | Project scaffolding | After Vite setup |
| `patchflow_task02_orderflow-bug_summary.png` | OrderFlow sample project | After bug implementation |
| `patchflow_task03_investigation-setup_summary.png` | Subagent setup | After configuring 4 subagents |
| `patchflow_task04_subagent-investigation_summary.png` | Investigation run | After parallel investigation |
| `patchflow_task05_patch-and-tests_summary.png` | Patch + regression test | After patch generation |
| `patchflow_task06_final-polish_summary.png` | Final polish | After UI completion |

## Why This Matters

The bob_sessions/ screenshots serve as the primary evidence that IBM Bob 2.0 was
genuinely used in this project — not just mentioned. Judges can see:

- Which Bob capabilities were used (Agent mode, subagents, parallel tasks)
- Bobcoin consumption (budget tracking)
- Task complexity and duration
- What the AI actually produced

This is a hackathon compliance requirement per the project specification.
